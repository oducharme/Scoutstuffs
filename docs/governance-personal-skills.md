# Personal skill governance

This repository stores personal Scout skill source files only. It is not a manuscript repository and must not contain customer, tenant, M365, FastTrack, or enterprise-derived content.

## Rules

- Personal skills use distinct names from shared enterprise skills.
- Personal project files stay under `C:\Personal stuff` unless the user explicitly confirms an exception.
- Wolfdream work uses French by default.
- Enterprise tools and context are not used for personal creative projects.
- Personal project memories and skills are ignored during enterprise work.
- Enterprise memories and skills are ignored during personal project work.
- Purview `Non-business/Personal` labeling may be used when explicitly requested for personal printing or personal sharing.

## Source-of-truth model

- GitHub stores skill/tooling instructions.
- `C:\Personal stuff` stores creative artifacts and manuscript files.
- Local reprise/canon documents are authoritative for project facts.
- Memories are high-salience routing hints, not the canon source of truth.
