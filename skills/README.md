# Personal Local Skills

This folder contains personal/local Scout skills only. They are not shared Scout skills, are not installed under `~\.scout\m-skills` or `~\.copilot\m-skills`, and should not be registered, deployed, or made to pass Skill Guard.

## Inventory

| Skill | Purpose | Primary scope |
|---|---|---|
| `dnd-local` | DND campaign/canon/project workflow | `C:\Personal stuff\DND` |
| `homebrewery-local` | Homebrewery source, login, live-edit, and render validation workflow | Personal brews, usually `C:\Personal stuff\DND\...\Homebrewery` |
| `map-making-local` | Personal creative/TTRPG cartography workflow | `C:\Personal stuff` |
| `wolfdream-local` | Wolfdream reprise, canon, prose, and manuscript workflow | `C:\Personal stuff\Wolfdream` |

## Shared local-only rules

- Keep all work under `C:\Personal stuff` unless the user explicitly approves a one-off exception.
- Do not use enterprise data, customer data, Microsoft 365 work data, FastTrack tools, or enterprise MCP servers.
- Do not copy these skills into m-skills or ask Skill Guard to protect/validate them.
- Prefer local project artifacts over memory when resolving canon or project state.
- Preserve backups before editing Office files or important source artifacts.
- Remove or move accidental outputs that land in governed Scout folders.
